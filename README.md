# 4부 찬양대 베이스 배치도

교회 성가대(66명) 좌석 배치를 PC/모바일 브라우저에서 직접 편집·저장·이미지로 공유하는 단일 HTML 도구.

## 사용 방법

### 아이폰/모바일 (추천): 홈 화면에 추가

1. 인터넷 되는 곳에서 **Safari로** 배포 주소를 엽니다: **https://jayden-choo-aki.github.io/seating-chart/**
   - 카카오톡에서 링크를 열었다면 먼저 하단 메뉴(⋯)에서 **"Safari로 열기"**를 누르세요. 카톡 인앱 브라우저에서는 홈 화면 추가가 안 됩니다.
2. 화면 하단 가운데 **공유 버튼(⬆︎)** → 아래로 스크롤 → **"홈 화면에 추가"** → **"추가"**를 누릅니다.
3. 이후에는 홈 화면의 "베이스 배치도" 아이콘으로 실행 — **인터넷이 전혀 없는 곳에서도 동작**합니다.
   - 카카오톡으로 받은 HTML 파일의 미리보기(바로보기)로는 열리지 않습니다(안내 문구만 표시). 반드시 위 방법으로 설치하거나 링크로 접속해 주세요.
   - 온라인 상태에서 열면 최신 버전으로 자동 갱신됩니다.

### HTML 파일로 보관 (PC용 오프라인 백업)

배포 페이지 툴바의 **[HTML 다운로드]** 버튼을 누르면 `베이스배치도.html` 단일 파일이 저장됩니다.

- **PC/Mac 전용**: 더블클릭으로 열면 인터넷 없이 동작합니다.
- **아이폰에서는 이 파일을 실행할 수 없습니다.** 파일 앱에서 열면 iOS 미리보기(QuickLook)로 열려 화면이 나오지 않습니다(자바스크립트 미실행). 아이폰 오프라인 사용은 위의 "홈 화면에 추가" 방식을 쓰세요.
- 이 버튼은 웹 주소로 접속했을 때만 보입니다(내려받은 파일에서는 숨김).

### PC

1. `index.html`을 브라우저로 열기 (더블클릭). **인터넷 연결 불필요** — 이 파일 하나만 있으면 어디서든 동작합니다.
2. 단원 카드를 클릭(또는 드래그) → 빈 좌석을 클릭(또는 드롭).
3. 배치된 좌석을 클릭해 선택한 뒤 다른 좌석 클릭 → 빈 좌석이면 이동, 배치된 좌석이면 서로 교체.
4. 점유 좌석 더블클릭(모바일: 더블탭)으로 배치 해제, 길게 누르면(0.5초) 단원 이름/메모 수정.
5. [PNG 다운로드]로 이미지 저장, 카카오톡/밴드 등에 공유.

## 주요 기능

- 드래그&드롭(PC) + 탭 선택(모바일) 배치
- 🎲 랜덤배치 — 누를 때마다 전체 단원을 좌석에 무작위 재배치
- 좌석 클릭 선택 → 다른 좌석으로 이동/서로 교체
- 한글 가나다 자동 정렬, 초성(ㄱ~ㅎ) 필터
- 좌·우 9행 레이아웃 직접 편집
- 브라우저 localStorage 자동 저장
- PNG 이미지 다운로드 (콘텐츠 폭에 맞춰 여백 없이 캡처. 홈 화면 설치형 앱에서는 공유 시트가 열려 "이미지 저장"/카톡 공유 가능)
- HTML 파일 다운로드 (웹 접속 시에만 표시, 오프라인 보관용 단일 파일)
- 완전 오프라인 동작 (html2canvas 파일 내 인라인, 단일 HTML)

## 데이터 위치

브라우저 localStorage 키: `seating-chart-v1`
시크릿 모드에서는 저장이 비활성화되며 상단에 경고가 표시됩니다.

## 자가테스트

`index.html?test=1`로 열면 콘솔에 자가테스트 결과가 출력됩니다.
